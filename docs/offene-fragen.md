# Offene Fragen & Entscheidungen

Stand 24.10.2026 · Ergänzung zu `00_KONZEPT_Onboarding-Tool.md`

## Schon entschieden
- Reines Social-Media- und Werbe-Tool, **keine Kassa-Anbindung**. Messbarkeit steht als Empfehlung im Konzept.
- Das Tool heißt wie die Agentur: **the first thought**.
- **Kunden bearbeiten nichts.** Sie kommentieren und geben frei, per Link mit PIN.
- **Kunden-Bot über Telegram.** Alle Nachrichten landen im Anfragen-Dashboard, vereinbarte Basics kommen sofort als Bild zurück.
- **Videos bleiben in SharePoint**, das Tool verlinkt nur.
- **Trend-Radar:** wöchentliches Viral-Briefing pro Kundentyp (Konzept 6c).
