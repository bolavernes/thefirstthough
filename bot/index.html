„Wir haben heute Seebarsch.“

Jeder Kunde bekommt einen eigenen Bot auf Telegram. Alles, was er schreibt, landet gesammelt im Dashboard. Die mit dem Kunden vereinbarten Basics (Tagesangebot, offen/geschlossen, Schlechtwetter) schickt der Bot sofort als fertiges Bild zurück. Alles andere wird eine Anfrage an euch.

Dashboard daneben öffnen →

  1. Wirt schreibt „Heute Seebarsch vom Grill 24,90“ oder „Ich brauch ein Foto vom neuen Burger“.
  2. Claude ordnet ein: Ist es ein vereinbartes Basic oder eine Anfrage ans Team?
  3. Basic: 3 Varianten im Brand-Kit, Foto aus der Mediathek, „Nimm 2“, fertiges Bild kommt zurück.
  4. Anfrage: landet sofort im Dashboard mit Kunde, Art und Frist. Der Wirt bekommt eine Bestätigung.
  5. Alles dokumentiert: Jede Nachricht steht im Dashboard, auch die automatisch erledigten.
